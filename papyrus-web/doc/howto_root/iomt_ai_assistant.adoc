== LLM direct question

*NOTE:* the following steps have a specific application scenarios, but may be generalized and used in other existing models.

Open the model that has been created in previous steps (_Devices Model_) to start chatting with the Large-Language Model about the modeling task. It is necessary to select _LLM Playground_ to open the chat in the right-side panel.

Choose _Direct LLM question_: this means it makes questions to the LLM without any additional document. 

image:llm_iomt_general.png[]

- Select the model root element _devices_.
- Click in the _Add model_ button in the chat. It adds the model in the PlantUML textual format to the input prompt. It provides the context to the LLM.
- Ask a question about the model, for instance:

 "Could you identify any possible improvements in this model ? "

The LLM will answer if there are any specific modifications to be done. The user is free to apply them or not. The answer may vary, even for the same question. The screenshot below show one specific answer.

image:llm_iomt_direct_answer.png[]

== Questioning the LLM using RAG

RAG (Retrieval Augmented Generation) enables adding additional documents to the context of the question that is done to the LLM. 

The tool supports uploading PDFs that serve as additonal context. The PDFs may be dowloaded directly using the main menu over the root element, option _Upload PDF to RAG_. The added PDFs are specific to each project. 

The PDF in this link may be uploaded into the project: link:./pdfs/code_plantuml_iomt.pdf[PDF uploaded to the RAG system]

image:cpp_generation.png[Upload PDF]

*NOTE:* The link https://papyrus-web.deeplab.fr/uploadfiles provides an interface for document management per project (inclusion and exclusion). The _project ID_ is extracted from the navigator URL. In the sample below, it is '13bd4f0a-6d44-495a-9cd3-7d31badcd6bc'.

[source, ]
----
https://papyrus-web.deeplab.fr/projects/13bd4f0a-6d44-495a-9cd3-7d31badcd6bc/edit/
----

The RAG utilisation is similar to a direct question, but it has as main goal retrieving PlantUML excerpts that may be added to the main model.

Select the _UML RAG_ option, add the PlantUML to the prompt and make a specific question, for instance:

_Could you add classes about communication and cloud infrastructure, using the context ?_

A sample answer is shown below. The user may integrate the response into the model using the editor.
