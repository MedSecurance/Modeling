= IoMTComponentCategories UML Profile Documentation

This document provides a description of the `IoMTComponentCategories` UML profile, including stereotypes, attributes, and associations. It enables annotating the IoMT elements to specify the system's supported features.

This profile is used together with the IoMT profile, which defines the core architectural elements.

== Stereotypes

=== IoMTcomponent

The `IoMTcomponent` stereotype is applied to IoMT classes and it is used to indicate that given IoMT element supports specific IoMT features.

==== Attributes

|===
| Name | Type | Multiplicity | Description

| supportedFeatures
| ComponentAnnotationKind
| 0..*
| The features supported by this IoMT stereotype.
|===

=== IoMTp

The `IoMTp` stereotype is applied to IoMT properties and it is used to indicate that given IoMT property supports specific IoMT features.

==== Attributes

|===
| Name | Type | Multiplicity | Description


| supportedFeatures
| PropertyAnnotationKind
| 0..*
| The features supported by this IoMT stereotype.
|===

=== IoMTpkg

The `IoMTpkg` stereotype stereotype is applied to IoMT pacakges and it is used to indicate that given IoMT element supports specific IoMT features.

==== Attributes

|===
| Name | Type | Multiplicity | Description


| supportedFeatures
| PackageAnnotationKind
| 0..*
| The features supported by this IoMT package.
|===
